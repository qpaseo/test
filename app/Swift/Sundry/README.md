# Swift 개발을 위한 Xcode 기능 및 플러그인

Xcode는 Apple 플랫폼용 애플리케이션을 개발하기 위한 통합 개발 환경(IDE)입니다.

### Swift 개발을 위한 Xcode 기능

*   **SwiftUI 실시간 프리뷰:** 더 빠른 디자인 반복을 위한 즉각적인 시각적 피드백.
*   **코드 완성 및 제안:** 코드를 더 빨리 작성할 수 있도록 상황에 맞는 완성 및 제안 기능.
*   **리팩토링 도구:** 프로젝트 전체에서 일관되게 코드의 이름을 바꾸고, 추출하고, 수정합니다.
*   **디버깅 도구:** 문제를 식별하고 수정하는 강력한 디버거.
*   **Instruments:** 성능 병목 현상을 식별하고 해결하는 성능 분석 도구.
*   **소스 컨트롤 통합:** Git 및 GitHub 내장 지원.

### Swift 개발용 Xcode 플러그인

*   **SwiftLint:** 일관된 코드 스타일을 적용하고 잠재적인 문제를 식별하는 린터.
*   **SwiftFormat:** 미리 정의된 스타일에 맞게 Swift 코드를 자동으로 포맷합니다.
*   **XVim2:** Xcode에 Vim 편집기 기능을 제공합니다.
*   **SwiftMockGeneratorForXcode:** 단위 테스트를 위한 모의 클래스를 자동으로 생성합니다.
*   **Dash:** Xcode와 통합된 강력한 문서 브라우저.
