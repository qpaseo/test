# Swift: Apple's Core Frameworks

이 문서는 Apple이 iOS, macOS 등 자사 플랫폼 개발을 위해 기본적으로 제공하는 핵심 프레임워크들을 설명합니다.

## 1. SwiftUI

-   **카테고리**: UI 툴킷
-   **설명**: SwiftUI는 모든 Apple 플랫폼에서 앱을 구축하기 위한 현대적이고 선언적인 방식의 UI 프레임워크입니다. "무엇을" 보여줄지를 코드로 기술하면, SwiftUI가 "어떻게" 그릴지를 알아서 처리합니다. 상태(`@State`)가 변경되면 뷰(View)가 자동으로 업데이트되어, UI 개발을 더 빠르고 직관적으로 만들어줍니다.
-   **특징**:
    -   **선언적 구문**: 간결하고 읽기 쉬운 코드로 뷰를 구성합니다.
    -   **모든 Apple 플랫폼 지원**: iOS, iPadOS, macOS, watchOS, tvOS에서 동일한 코드로 UI를 빌드할 수 있습니다.
    -   **실시간 프리뷰**: 코드 변경사항을 Xcode 프리뷰에서 즉시 확인할 수 있습니다.

## 2. Combine

-   **카테고리**: 반응형 프로그래밍 (Reactive Programming)
-   **설명**: Combine은 시간에 따라 변하는 값을 처리하기 위한 선언적인 Swift API를 제공하는 프레임워크입니다. 사용자 입력, 네트워크 응답, 데이터 변경 등 비동기적인 이벤트를 스트림(Stream) 형태로 처리할 수 있습니다.
-   **주요 구성 요소**:
    -   **Publisher**: 값을 생성하고 전달하는 역할.
    -   **Subscriber**: Publisher로부터 값을 받아 처리하는 역할.
    -   **Operator**: Publisher가 전달하는 값을 변환하거나 필터링하는 역할.
-   **용도**: SwiftUI의 데이터 흐름과 자연스럽게 통합되며, 비동기 이벤트 처리를 위한 통일된 방법을 제공합니다.

## 3. Swift Concurrency (`async`/`await`)

-   **카테고리**: 비동기 프로그래밍 (Asynchronous Programming)
-   **설명**: Swift 5.5부터 언어 수준에서 지원되는 비동기 프로그래밍 모델입니다. `async` 키워드로 비동기 함수를 정의하고, `await` 키워드로 해당 함수가 완료될 때까지 순차적으로 기다릴 수 있습니다. 복잡한 클로저(closure) 기반의 비동기 코드를 구조적이고 읽기 쉽게 만들어줍니다.
-   **주요 구성 요소**:
    -   `async`/`await`: 비동기 코드를 동기 코드처럼 작성하게 해줍니다.
    -   `Task`: 비동기 작업을 생성하고 관리하는 단위입니다.
    -   `Actor`: 여러 스레드에서 상태에 안전하게 접근할 수 있도록 동시성 문제를 해결해주는 타입입니다.

## 4. `URLSession`

-   **카테고리**: 네트워킹 (Networking)
-   **설명**: HTTP 및 기타 인터넷 프로토콜을 통해 데이터를 다운로드하고 업로드하는 API를 제공하는 Apple의 기본 프레임워크입니다.
-   **특징**:
    -   Swift Concurrency와 완벽하게 통합되어 `async`/`await`를 사용하여 네트워크 요청을 매우 간결하게 작성할 수 있습니다.
    -   백그라운드 다운로드, 캐싱 정책, 인증 처리 등 강력하고 세밀한 네트워킹 제어 기능을 제공합니다.
    -   `Alamofire`와 같은 서드파티 라이브러리들은 내부적으로 `URLSession`을 기반으로 더 편리한 API를 제공하는 경우가 많습니다.
