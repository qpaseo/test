# Kotlin: Official & Core Libraries

이 문서는 Kotlin 언어에 내장되어 있거나, JetBrains 또는 Google에서 안드로이드 개발을 위해 핵심적으로 지원하는 공식 라이브러리들을 설명합니다.

## 1. Kotlin Coroutines (코루틴)

-   **카테고리**: 비동기 프로그래밍 (Asynchronous Programming)
-   **설명**: 코루틴은 비동기 코드를 동기 코드처럼 간결하고 순차적으로 작성할 수 있게 해주는 Kotlin의 언어 수준 기능입니다. 콜백 지옥(Callback Hell)을 피하고, 복잡한 비동기 로직을 쉽게 관리할 수 있도록 도와줍니다. 안드로이드에서는 UI 스레드를 차단하지 않고 네트워크 요청이나 데이터베이스 작업을 처리하는 데 필수적으로 사용됩니다.
-   **주요 구성 요소**:
    -   `suspend` 함수: 일시 중단 및 재개가 가능한 함수입니다.
    -   `CoroutineScope`: 코루틴의 생명주기를 관리하는 컨텍스트입니다.
    -   `Dispatchers`: 코루틴을 어떤 스레드에서 실행할지 지정합니다. (`Main`, `IO`, `Default`)
    -   `launch`, `async`: 코루틴을 시작하는 빌더 함수입니다.

## 2. Flow (플로우)

-   **카테고리**: 반응형 프로그래밍 (Reactive Programming)
-   **설명**: 코루틴을 기반으로 만들어진 반응형 스트림(Reactive Stream) 라이브러리입니다. 여러 개의 값을 순차적으로 비동기적으로 생성(emit)하고 처리할 수 있습니다. 데이터베이스 변경 감지, 실시간 위치 업데이트, 사용자 입력 스트림 등 시간에 따라 변하는 데이터를 처리하는 데 매우 유용합니다.
-   **종류**: `Flow` (Cold Stream), `StateFlow` (상태를 나타내는 Hot Stream), `SharedFlow` (여러 구독자에게 이벤트를 전달하는 Hot Stream)

## 3. Jetpack Compose

-   **카테고리**: UI 툴킷
-   **설명**: Google에서 개발한 안드로이드 최신 UI 툴킷입니다. XML 레이아웃 대신, Kotlin 코드를 사용하여 선언적으로 UI를 구성합니다. 상태(`State`)가 변경되면 UI가 자동으로 업데이트되어, UI 개발을 더 빠르고 직관적으로 만들어줍니다.
-   **특징**:
    -   **선언적 UI**: "무엇을" 그릴지 코드로 정의하면, Compose가 "어떻게" 그릴지 처리합니다.
    -   **재사용 가능한 컴포저블**: `@Composable` 어노테이션을 붙인 함수로 UI 조각을 만들어 재사용합니다.
    -   **상태 관리**: `remember`, `mutableStateOf` 등을 사용하여 컴포넌트의 상태를 관리합니다.

## 4. Ktor

-   **카테고리**: 네트워킹, 웹 프레임워크
-   **설명**: JetBrains에서 개발한 비동기 웹 프레임워크입니다. 서버(Server)와 클라이언트(Client)를 모두 만들 수 있습니다. 안드로이드에서는 `Retrofit`의 대안으로 Ktor Client를 사용하여 타입-세이프한 HTTP 통신을 구현할 수 있습니다. 코루틴을 기반으로 설계되어 비동기 처리가 매우 자연스럽습니다.
