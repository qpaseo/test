# Nest.js

이 디렉토리는 Node.js 서버-사이드 애플리케이션을 구축하기 위한 프레임워크인 Nest.js와 관련된 다양한 개념과 기술을 정리합니다.

## 주제

*   [Grammar](./Grammar/README.md) - 모듈, 컨트롤러, 프로바이더 등 핵심 아키텍처
*   [Hook](./Hook/README.md) - 생명주기 이벤트 (Lifecycle Events)
*   [PageRouting](./PageRouting/README.md) - 컨트롤러를 이용한 라우팅
*   [ServerCommunication](./ServerCommunication/README.md) - 데이터베이스 및 다른 서비스와의 통신
*   [Summary](./Summary/README.md) - Nest.js 요약
*   [Sundry](./Sundry/README.md) - 파이프, 가드, 인터셉터, 필터 등
*   [type](./type/README.md) - TypeScript 및 DTO(Data Transfer Object)
*   [UI](./UI/README.md) - 프론트엔드 연동 및 템플릿 엔진
