# React UI Frameworks, Libraries & Patterns

이 문서는 React 애플리케이션의 UI를 구축하는 데 사용되는 다양한 UI 프레임워크, 컴포넌트 라이브러리, 그리고 UI 패턴에 대해 설명합니다.

## 1. Component Libraries (컴포넌트 라이브러리)

미리 스타일링된 다양한 UI 컴포넌트 모음을 제공하여 개발 속도를 높이고 일관된 디자인을 유지할 수 있도록 도와줍니다.

-   **Material-UI (MUI)**: Google의 Material Design을 기반으로 하는 가장 인기 있는 React UI 프레임워크입니다.
-   **Ant Design (AntD)**: 엔터프라이즈급 애플리케이션을 위한 고품질의 UI 컴포넌트 세트를 제공합니다.
-   **Chakra UI**: 접근성을 중시하며, 스타일 프롭(style props)을 사용하여 매우 유연하고 빠르게 UI를 구성할 수 있는 라이브러리입니다.
-   **React-Bootstrap**: Bootstrap을 React 컴포넌트로 재구축한 라이브러리입니다.
-   **Headless UI**: 스타일이 적용되지 않은 순수 기능 및 접근성만 갖춘 컴포넌트 라이브러리로, Tailwind CSS와 함께 사용하기 좋습니다.

## 2. CSS Frameworks (CSS 프레임워크)

UI 컴포넌트보다는 스타일링 클래스나 도구를 제공하여 UI를 구축하는 데 도움을 줍니다.

-   **Tailwind CSS**: 유틸리티 우선(Utility-First) CSS 프레임워크로, 클래스를 조합하여 매우 빠르게 UI를 개발할 수 있습니다.

## 3. UI Patterns & Techniques

UI 개발 시 사용자 경험을 향상시키기 위해 사용되는 일반적인 패턴과 기법들입니다.

-   **[Skeleton UI](./SKELETON.md)**: 데이터가 로드되기 전에 컨텐츠의 레이아웃을 미리 보여주는 UI 패턴입니다. 로딩에 대한 인지 성능을 크게 향상시킵니다.
