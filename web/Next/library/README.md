# Next.js: Official & Vercel-Made Libraries

이 문서는 Next.js 프레임워크에 내장되어 있거나, 개발사인 Vercel에 의해 직접 개발되어 Next.js와 함께 사용하기 좋은 라이브러리들을 설명합니다.

## 1. `next/image`

-   **카테고리**: 이미지 최적화
-   **설명**: HTML의 `<img>` 태그를 확장한 컴포넌트로, 이미지 최적화를 자동으로 수행합니다.
-   **주요 기능**:
    -   **크기 최적화**: 디바이스 크기에 맞는 최적의 이미지 사이즈를 제공합니다.
    -   **포맷 최적화**: 브라우저가 지원하면 WebP와 같은 최신 이미지 포맷으로 자동 변환합니다.
    -   **지연 로딩 (Lazy Loading)**: 이미지가 뷰포트에 들어올 때만 로드하여 초기 로딩 속도를 개선합니다.
    -   **CLS 방지**: 이미지 공간을 미리 확보하여 레이아웃이 밀리는 현상(Cumulative Layout Shift)을 방지합니다.

## 2. `next/font`

-   **카테고리**: 폰트 최적화
-   **설명**: 웹 폰트(특히 구글 폰트)를 사용할 때 성능과 개인정보보호를 위해 최적화해주는 기능입니다.
-   **주요 기능**:
    -   **자동 Self-hosting**: 빌드 시점에 폰트 파일을 다운로드하여 서버 에셋과 함께 호스팅하므로, 외부 네트워크 요청이 발생하지 않습니다.
    -   **CLS 방지**: 폰트 로딩으로 인한 레이아웃 밀림을 방지하기 위해 CSS의 `size-adjust` 속성을 자동으로 사용합니다.

## 3. `next/script`

-   **카테고리**: 스크립트 최적화
-   **설명**: Google Analytics나 각종 SDK와 같은 서드파티 스크립트를 페이지에 추가할 때, 로딩 시점과 전략을 제어하여 성능을 최적화하는 컴포넌트입니다.
-   **주요 기능 (`strategy` 속성)**:
    -   `afterInteractive` (기본값): 페이지가 상호작용 가능해진 후에 스크립트를 로드합니다.
    -   `lazyOnload`: 브라우저가 유휴 상태일 때 스크립트를 로드합니다.
    -   `beforeInteractive`: 페이지 상호작용 전에 스크립트를 로드합니다. (중요한 스크립트에만 사용)

## 4. SWR

-   **카테고리**: 데이터 페칭 (Data Fetching)
-   **설명**: Vercel에서 만든 데이터 페칭을 위한 React Hooks 라이브러리입니다. `stale-while-revalidate`라는 HTTP 캐시 전략의 이름을 따왔으며, 캐시된 데이터를 먼저 보여준 후 백그라운드에서 최신 데이터를 가져와 UI를 업데이트하는 방식으로 빠르고 부드러운 사용자 경험을 제공합니다.
-   **특징**: TanStack Query와 유사한 역할을 하지만, 더 가볍고 간단한 API를 지향합니다. Next.js의 클라이언트 컴포넌트에서 데이터를 가져올 때 훌륭한 선택지입니다.
